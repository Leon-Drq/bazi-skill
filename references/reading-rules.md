# 八字判读规则

## 十神

以日干为“我”：同我为比劫，我生为食伤，我克为财，克我为官杀，生我为印。阴阳相同/相异再分偏正：比肩/劫财、食神/伤官、偏财/正财、七杀/正官、偏印/正印。

## 日主强弱

至少交叉检查：

1. 月令：日主在当月的旺衰；
2. 通根：地支藏干中是否有同五行；
3. 透干：天干中比劫、印、官杀、财、食伤的分布；
4. 组合：合、冲、刑、害是否改变可用力量。

脚本的“身强/中和/身弱”只是可解释的初筛。不要仅凭五行数量下结论，也不要把“缺某元素”直接转换成必须佩戴或购买某物。

## 用神与专题

- 身强时通常先考虑疏泄、耗泄或制化方向；身弱时通常先考虑生扶方向；但调候、格局和寒燥湿润可能改变结论；
- 感情、事业、财务、健康必须分别提出问题，不用一张宽泛的“总体运势”替代具体事件；
- 大运/流年只描述“更容易出现的主题和需要留意的条件”，不给确定事件和精确日期；
- 健康相关内容只做作息、压力、运动、体检提醒，出现症状时以临床意见为准。
